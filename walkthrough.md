# Walkthrough: Órbita 180 - Ecossistema de Inteligência Empreendedora

## 🚀 Visão Geral
Órbita 180 é uma plataforma SaaS premium projetada para gerenciar e impulsionar ecossistemas de inovação. Ela conecta startups, instituições e mentores em uma jornada de evolução baseada em dados e inteligência estratégica.

## 🏗️ Arquitetura do Sistema
O projeto utiliza **Next.js 16** com **App Router**, **TypeScript**, **Prisma** e **Vanilla CSS** para uma experiência fluida e escalável.

### Módulos Implementados
1. **Dashboard Central (`/`)**: Visão 360º da startup, KPIs de faturamento, maturidade e agenda de eventos.
2. **CRM & WhatsApp (`/crm`)**: Funil de vendas Kanban integrado a uma simulação de WhatsApp Web para gestão de leads.
3. **Estratégia (`/estrategia`)**: Ferramentas de modelagem como Lean Canvas e estruturação de Pitch Deck.
4. **Comunidade (`/comunidade`)**: Feed social para interação entre membros do ecossistema, compartilhamento de conquistas e avisos.
5. **Maturidade (`/maturidade`)**: Análise profunda através de Mapa Radar, scores por categoria e planos de ação automatizados.

## 🎨 Design System
- **Estética**: Premium, Institucional, Tecnológica.
- **Cores**: Predominância de Branco (#FFFFFF), Azul Primário (#2563eb) e Cinza Neutro (#F8FAFC).
- **Tipografia**: Outfit (Headings) e Inter (Body).
- **Componentes**: Glassmorphism, Sombras Suaves, Micro-animações de entrada.

## 🛠️ Tecnologias
- **Frontend**: Next.js (React 19), Lucide React (Icons).
- **Styling**: Vanilla CSS (CSS Variables + CSS Modules/Styles).
- **Database**: Prisma ORM (Pronto para integração com PostgreSQL/SQLite).
